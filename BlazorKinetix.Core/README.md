# BlazorKinetix.Core

Shared types and text catalog for [BlazorKinetix](https://github.com/Kljuce1/BlazorKinetix).

Install `BlazorKinetix` to use the controls. NuGet installs this package as its dependency.

The library targets .NET 10 and supports Blazor Server and WebAssembly. See the [repository README](https://github.com/Kljuce1/BlazorKinetix#readme) for setup, examples, and documentation.
